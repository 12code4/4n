# v4.0 "The Living Maw" — Implementation Notes

Theme: the Maw notices you. The dungeon stops being terrain and starts being a
counterparty with moods, appetites, and a pulse.

## Systems

### Maw moods (weather)
- One mood at a time, 2–5 days: **Generous** (loot +25%, prices −15% — it floods
  the market), **Restless** (more fights, more caches), **Hungry** (enemies +15%
  stats, loot +40%), **Holding its Breath** (fewer fights, prices +20%, torches
  burn double), **Dreaming** (events twice as common, strange outcomes improve).
- Shown on the HUD as a phase-of-the-Maw glyph; forecast at Charter Hall L2+.
- Couples market drift AND run generation from one source — the design pillar
  ("the market's moods and the dungeon's moods are the same moods") made literal.

### Omens (run mutators)
- At outfitting, up to 2 omens offered (skippable): blessed & cursed pairs:
  e.g. *Omen of the Open Hand* (+30% loot, enemies +1 dmg), *Omen of Ash*
  (fire enemies everywhere, fire loot doubled), *Omen of the Quiet Stair*
  (no guardian this run, no guardian rewards), *Omen of Salt* (no rest nodes,
  +2 grit start).
- Persist for the whole expedition; stack with mood.

### Combat depth
- **Status effects**: Burn (dmg/turn, 2t), Chill (−spd, −dmg, 2t), Bleed
  (dmg-on-act, 3t), Ward (absorb next hit). Sources: class talents (new tier at
  L9), enemy specials, omens, gear tier 3+.
- **Enemy intents**: each enemy telegraphs next action (strike/aoe/summon/other)
  with an icon over its head — turns Guard/taunt into real decisions.
- Skill upgrade tiers hook into talents from v3.0.

### The Veins (depths 10–12)
- Living tunnel flesh, pulse-light; crimson palette that beats.
- Materials: **Pulse-Gem** (22), **Sinew Cord** (15), **Chorus Nectar** (19),
  **A Held Breath** (60, rare).
- Enemies: Pulse Leech, Marrow Knight, Chorus of Want (sings Want: delvers skip
  turns), Vein Shepherd, Clot Golem, The Smaller Wants.
- Guardian: **The Auricle** — the Maw's ear. Fights while LISTENING: repeats
  the party's own most-used action back at them, amplified.

### Companion beasts (Menagerie)
- New building **Menagerie**; beasts rescued via new deep events (Glasswing
  fledgling, orphan Cinder Hound, a Page Swarm that likes you).
- One beast per expedition: passive (+flee, +loot-find, +1 party dmg) plus one
  active use per fight (bite / fetch / shriek).
- Beasts can't die — they flee home when the fight is lost (they're smarter
  than the payroll).

### Charter Renewal (prestige)
- Retire the charter at any time from the Charter Hall: converts lifetime renown
  + banked marks + depth records into **Legacy Marks**.
- New game keeps: codex, achievements, Legacy tree. Legacy tree (~12 perks):
  starting capital, veteran founding roster, permanent +1 contract slot, mood
  forecast from day 1, cheaper buildings, "Maren's chalk" (event success +10%)…
- New-charter flavor: the sign over the door gains a numeral.

## Save migration v3 → v4
- add `mood`, `omens: []`, `beasts: {owned: [], active: null}`, `legacy:
  {marks: 0, perks: []}`, buildings `menagerie: 0`; delver/enemy status arrays
  exist only in combat state (no migration needed).
